A tiny Python program that writes exactly one emoji to `/output/entry.txt`: 🌞, the sun with a face — a single character (one Unicode code point) chosen as the emoji most likely to make a stranger smile. The pick was made by duelling fifteen candidate emojis against the bounty judge's own criteria, in order — warmth a stranger reads at first glance, universality across ages and backgrounds, a chosen-rather-than-default feel, and nothing intimate, sarcastic or flirtatious. The plain 😊 fell on the "default" criterion; the hugging face fell on stranger-intimacy; the sunflower reached the final but lost to a rival that, unlike a flower, smiles back. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
